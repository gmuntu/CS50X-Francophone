### 4. Robust Programming (Input Validation)
A "good" programmer never trusts user input. To prevent a user from entering a negative number or a zero when you need a positive size, use a **`do-while` loop**:
```c
do
{
    n = get_int("Size: ");
}
while (n < 1); // Keep asking as long as the input is invalid
```

### 5. Data Types & Memory
Every piece of data in C has a **Type**. Choosing the wrong type can lead to **Integer Overflow** (where a number becomes too large for the memory allocated to it, causing it to "wrap around" to a wrong value).

| Type | Description |
| :--- | :--- |
| `bool` | True or False. |
| `char` | A single character (e.g., 'A', '7'). |
| `int` | Standard integer (whole number). |
| `long` | A larger integer for very big numbers. |
| `float` | A decimal number (real number). |
| `double` | A more precise decimal number. |
| `string` | A sequence of characters (text). |
